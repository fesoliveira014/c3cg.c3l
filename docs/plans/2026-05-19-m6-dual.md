# M6 — Dual Operation Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement `cg::dual` module with `dual()` and `dual_from_vertices()` — the central bridge between triangulation and Voronoi representations.

**Architecture:** Two-pass algorithm built on `from_polygons`. Each source vertex becomes a dual face whose ring is the source's one-ring of incident faces. The dual mesh is constructed via CSR `from_polygons` with vertex positions at `dual_vertex_positions[f]` for each source face `f`. A convenience wrapper `dual()` selects position-generation strategy via a `DualMode` enum.

**Spec:** `docs/superpowers/specs/2026-05-19-m6-dual-design.md`

**Tech Stack:** C3 0.8.0, c3c, existing `cg`, `cg::half_edge`, `cg::geometry` modules.

**Stub-then-replace:** Tasks 1–3 create infrastructure stubs to keep `c3c build debug && c3c test` green at every commit. Tasks 4+ replace stubs with real code, one capability at a time.

```c3
module cg::dual;
import cg;
import cg::half_edge;

fn HalfEdgeMesh? dual_from_vertices(Allocator alloc, HalfEdgeMesh* mesh, Vec3f[] dual_vertex_positions)
{
    mesh.validate()!;

    if (dual_vertex_positions.len != mesh.faces.len) return cg::DUAL_VERTEX_COUNT_MISMATCH~;

    for (usz i = 0; i < mesh.half_edges.len; i++) {
        if (mesh.half_edges[i].twin == cg::INVALID_HE) return cg::DUAL_REQUIRES_CLOSED_MESH~;
    }

    // --- Pass 1: collect ring sizes ---
    uint[] face_offsets = mem::alloc::new_array(alloc, uint, (sz)(mesh.vertices.len + 1));
    defer catch free(face_offsets);

    FaceIndex[] scratch = mem::alloc::new_array(alloc, FaceIndex, (sz) 3);
    defer free(scratch);

    face_offsets[0] = 0;
    for (usz v = 0; v < mesh.vertices.len; v++) {
        int n = 0;
        while (true) {
            int? result = mesh.vertex_one_ring_faces((VertexIndex)(int)v, scratch);
            if (catch err = result) {
                if (err == cg::OUTPUT_BUFFER_TOO_SMALL) {
                    // Grow scratch and retry.
                    usz new_cap = scratch.len * 2;
                    free(scratch);
                    scratch = mem::alloc::new_array(alloc, FaceIndex, (sz) new_cap);
                    continue;
                }
                return err?;
            }
            n = result!!;
            break;
        }
        face_offsets[v + 1] = face_offsets[v] + (uint)n;
    }

    // --- Allocate face indices ---
    uint[] face_indices = mem::alloc::new_array(alloc, uint, (sz) face_offsets[mesh.vertices.len]);
    defer catch free(face_indices);

    // --- Pass 2: fill face indices ---
    for (usz v = 0; v < mesh.vertices.len; v++) {
        int n = mesh.vertex_one_ring_faces((VertexIndex)(int)v, scratch)!;
        for (int i = 0; i < n; i++) {
            face_indices[face_offsets[v] + (uint)i] = (uint)scratch[i];
        }
    }

    // --- Construct mesh ---
    HalfEdgeMesh result = half_edge::from_polygons(alloc, dual_vertex_positions, face_offsets, face_indices)!;

    free(face_offsets);
    free(face_indices);
    return result;
}
```

Append to `src/dual/dual.c3`:

```c3
import cg::geometry;

enum DualMode : uint
{
    CIRCUMCENTER,
    CENTROID,
    SPHERICAL_CIRCUMCENTER,
}

fn HalfEdgeMesh? dual(Allocator alloc, HalfEdgeMesh* mesh, DualMode mode, float radius)
{
    Vec3f[] positions;
    switch (mode) {
        case DualMode.CIRCUMCENTER:
            positions = geometry::circumcenters_planar(alloc, mesh)!;
        case DualMode.CENTROID:
            positions = geometry::face_centroids(alloc, mesh)!;
        case DualMode.SPHERICAL_CIRCUMCENTER:
            positions = geometry::circumcenters_on_sphere(alloc, mesh, radius)!;
    }
    defer free(positions);
    return dual_from_vertices(alloc, mesh, positions)!;
```

## Debugging Notes

If Task 9 (icosahedron → dodecahedron) fails, common causes:

1. **`DUPLICATE_HALF_EDGE` from `from_polygons`** — The one-ring face walk order doesn't produce valid polygon rings. Check that `vertex_one_ring_faces` returns CCW order and that no vertex appears twice in a ring.

2. **Face degree ≠ 5** — Some dual faces aren't pentagons. This means the ring collection is incomplete or contains duplicates. Add a debug assertion that each ring has unique face indices.

3. **`INDEX_OUT_OF_RANGE`** — A `FaceIndex` in `face_indices` exceeds `dual_vertex_positions.len - 1`. Check that `face_indices` values are in `[0, source.faces.len)`.
