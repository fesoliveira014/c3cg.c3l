### Task 1: Implement voronoi module (GREEN)

**Files:**

- Create: `src/voronoi/voronoi.c3`
- Modify: `src/c3cg.c3i`

**Step 1: Add umbrella**

```c3
module cg::voronoi;
import cg;

struct VoronoiDiagram { HalfEdgeMesh mesh; Vec3f[] sites; }

fn VoronoiDiagram? from_delaunay(Allocator alloc, HalfEdgeMesh* delaunay);
fn HalfEdgeMesh? to_delaunay(Allocator alloc, VoronoiDiagram* diagram);
```

**Step 2: Implement `from_delaunay`**

1. `delaunay.validate()!`
2. Scan `half_edges` for `twin == INVALID_HE` → `OPEN_CELL_ON_BOUNDARY`
3. `centers = geometry::circumcenters_planar(alloc, delaunay)!`
4. `mesh = dual::dual_from_vertices(alloc, delaunay, centers)!`; `defer free(centers)`
5. Allocate `sites = copy(delaunay.positions)`
6. Return `VoronoiDiagram { mesh, sites }`

**Step 3: Implement `to_delaunay`**

```c3
return dual::dual_from_vertices(alloc, &diagram.mesh, diagram.sites)!;
```
