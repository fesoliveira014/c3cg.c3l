# M12 — Spherical Delaunay and Voronoi Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add `delaunay_on_sphere`, `voronoi_on_sphere`, `voronoi_dual_sphere`, and `centroids_on_sphere` to the c3cg library.

**Architecture:** Three new implementation files compose existing building blocks (`hull_3d`, `circumcenters_on_sphere`, `face_centroids`, `dual_from_vertices`) with minimal new logic: reproject hull vertices to sphere surface, normalize centroids, and wrap them in VoronoiDiagram. All new public API declared in `src/c3cg.c3i`.

**Spec:** `docs/specs/2026-05-22-m12-spherical-design.md`

**Key existing APIs used:**
- `hull::hull_3d(alloc, points)` → closed triangular HalfEdgeMesh
- `geometry::circumcenters_on_sphere(alloc, mesh, radius)` → sphere-projected circumcenters
- `geometry::face_centroids(alloc, mesh)` → planar face centroids
- `dual::dual_from_vertices(alloc, mesh, spatial_points)` → dual mesh
- `voronoi::to_delaunay(alloc, diagram)` → reverse dual (calls dual_from_vertices)

## Shared test constants

Put `ICO_SPHERE`, `ICO_PHI`, `ICO_R`, and `approx_abs` in `test/test_delaunay_sphere.c3` only (C3 test files share one `module test;` namespace). `test/test_voronoi_sphere.c3` references them without redeclaration.

### Task 2: Implement `centroids_on_sphere`

**Objective:** Replace the stub in `src/geometry/spherical.c3` with the real implementation.

**File:** `src/geometry/spherical.c3`

Replace entire file:

```c3
module cg::geometry;
import cg;
import std::math;

fn Vec3f[]? centroids_on_sphere(Allocator alloc, HalfEdgeMesh* tri_mesh, float radius)
{
    if (radius <= GEOMETRY_EPSILON) return cg::DEGENERATE_INPUT~;

    Vec3f[] centroids = face_centroids(alloc, tri_mesh)!;

    for (usz i = 0; i < centroids.len; i++) {
        float x = centroids[i].x;
        float y = centroids[i].y;
        float z = centroids[i].z;
        float len2 = x * x + y * y + z * z;
        if (len2 <= GEOMETRY_EPSILON * GEOMETRY_EPSILON) {
            free(centroids);
            return cg::DEGENERATE_INPUT~;
        }
        float inv_len = 1.0f / math::sqrt((double)len2);
        centroids[i] = {
            x * inv_len * radius,
            y * inv_len * radius,
            z * inv_len * radius,
        };
    }

    return centroids;
}
```

```c3
module cg::delaunay;
import cg;
import cg::hull;
import std::math;

fn HalfEdgeMesh? delaunay_on_sphere(Allocator alloc, Vec3f[] points, float radius)
{
    if (points.len == 0) return cg::EMPTY_INPUT~;
    if (points.len < 4) return cg::DEGENERATE_INPUT~;
    if (radius <= 0) return cg::DEGENERATE_INPUT~;

    HalfEdgeMesh mesh = hull::hull_3d(alloc, points)!;

    for (usz i = 0; i < mesh.positions.len; i++) {
        float x = mesh.positions[i].x;
        float y = mesh.positions[i].y;
        float z = mesh.positions[i].z;
        float len2 = x * x + y * y + z * z;
        if (len2 <= 0.0f) {
            mesh.destroy();
            return cg::DEGENERATE_INPUT~;
        }
        float inv_len = 1.0f / (float)math::sqrt((double)len2);
        mesh.positions[i] = {
            x * inv_len * radius,
            y * inv_len * radius,
            z * inv_len * radius,
        };
    }

    return mesh;
}
```

```c3
module cg::voronoi;
import cg;
import cg::delaunay;
import cg::geometry;
import cg::dual;

fn VoronoiDiagram? voronoi_on_sphere(Allocator alloc, Vec3f[] points, float radius)
{
    if (points.len == 0) return cg::EMPTY_INPUT~;
    if (points.len < 4) return cg::DEGENERATE_INPUT~;
    if (radius <= 0) return cg::DEGENERATE_INPUT~;

    HalfEdgeMesh tri_mesh = delaunay::delaunay_on_sphere(alloc, points, radius)!;
    defer tri_mesh.destroy();

    Vec3f[] centers = geometry::circumcenters_on_sphere(alloc, &tri_mesh, radius)!;
    defer free(centers);

    HalfEdgeMesh voronoi_mesh = dual::dual_from_vertices(alloc, &tri_mesh, centers)!;

    Vec3f[] sites = mem::alloc::new_array(alloc, Vec3f, (sz)points.len);
    defer catch {
        voronoi_mesh.destroy();
        free(sites);
    };
    for (usz i = 0; i < points.len; i++) sites[i] = points[i];

    VoronoiDiagram diagram;
    diagram.mesh = voronoi_mesh;
    diagram.sites = sites;
    return diagram;
}

fn VoronoiDiagram? voronoi_dual_sphere(Allocator alloc, HalfEdgeMesh* tri_mesh, Vec3f[] spatial_points)
{
    if (spatial_points.len == 0) return cg::EMPTY_INPUT~;
    return cg::EMPTY_INPUT~;
}
```
